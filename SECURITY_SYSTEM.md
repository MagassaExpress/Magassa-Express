# SECURITY SYSTEM

## Sécurité Magassa Express

### Vérification Téléphone

Tous les utilisateurs doivent vérifier leur numéro de téléphone.

Processus :

- Inscription
- Envoi d'un code SMS
- Validation du compte

Badge :

🟢 Téléphone Vérifié

---

## Vérification Identité

Documents acceptés :

- Carte NINA
- Carte biométrique
- Passeport

Badge :

🟢 Identité Vérifiée

---

## Vérification Commerce

Documents requis :

- RCCM
- NIF
- Pièce d'identité

Badge :

🔵 Commerce Vérifié

---

## Premium Vérifié

Conditions :

- RCCM validé
- NIF validé
- Identité validée
- Téléphone vérifié

Badge :

🟠 Premium Vérifié Magassa Express

---

## Limitation Anti-Spam

Compte Gratuit :

- Maximum 5 annonces par jour

Compte Starter :

- Maximum 20 annonces par jour

Compte Premium :

- Illimité

---

## Détection des Annonces Frauduleuses

Contrôles :

- Annonces dupliquées
- Faux prix
- Photos interdites
- Produits interdits

---

## Blocage Automatique

3 signalements graves :

- Mise sous surveillance

5 signalements confirmés :

- Suspension automatique

10 signalements confirmés :

- Bannissement définitif

---

## Historique Utilisateur

Informations visibles :

- Date d'inscription
- Nombre d'annonces
- Nombre de ventes
- Nombre d'avis
- Niveau de confiance

---

## Protection Acheteurs

Conseils affichés :

- Vérifier le produit avant paiement
- Ne jamais payer à l'avance
- Rencontrer le vendeur dans un lieu sûr
